# Bendita Tortilla · México → Berlín

Web estática con animaciones, calculadoras, gráficas, fuentes y documentos descargables.

## Publicar en GitHub Pages

1. Crear un repositorio público llamado `bendita-tortilla` en GitHub.
2. Subir el contenido de esta carpeta, conservando las subcarpetas. `index.html` debe estar directamente en la raíz del repositorio.
3. Guardar los archivos con **Commit changes**.
4. En **Settings → Pages**, elegir **Deploy from a branch**, rama **main** y carpeta **/(root)**; pulsar **Save**.
5. Abrir **Visit site** cuando finalice la publicación. La dirección será `https://TU-USUARIO.github.io/bendita-tortilla/`.

No subir únicamente el ZIP: hay que descomprimirlo y subir su contenido. No requiere Node, paquetes ni un servidor propio.

Para actualizar la página, reemplazar los archivos modificados y guardar un nuevo commit.

Documentación oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
